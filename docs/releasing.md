# Releasing The Grid

## Required GitHub Actions secrets

Before the release pipeline will work, set these three secrets in your fork/repo
(**Settings → Secrets and variables → Actions → New repository secret**):

| Secret | Description |
|---|---|
| `REGISTRY_HOST` | Hostname of your OCI registry (e.g. `ghcr.io`, `quay.io`, `123456789.dkr.ecr.us-east-1.amazonaws.com`) |
| `REGISTRY_USERNAME` | Username or account name for the registry |
| `REGISTRY_TOKEN` | Password or personal access token with push permissions |

For **GHCR**: use `${{ github.actor }}` as username (the secret is just the PAT).
For **ECR**: use the output of `aws ecr get-login-password` as the token (or configure OIDC).

## Release process

1. **Bump the chart version** in `charts/the-grid-synthetics/Chart.yaml`:
   ```yaml
   version: 0.2.0   # must match the git tag you are about to push
   appVersion: 0.2.0
   ```

2. **Commit and push** the version bump:
   ```bash
   git add charts/the-grid-synthetics/Chart.yaml
   git commit -m "Bump chart version to 0.2.0"
   git push origin main
   ```

3. **Tag and push**:
   ```bash
   git tag v0.2.0
   git push origin v0.2.0
   ```

4. The `release.yml` workflow validates that the tag matches `Chart.yaml`, then builds and pushes:
   - Operator image: `<REGISTRY_HOST>/the-grid/operator:v0.2.0` and `:latest`
   - Helm chart: `oci://<REGISTRY_HOST>/charts/the-grid-synthetics` version `0.2.0`

5. **Verify** (after CI completes):
   ```bash
   docker pull <REGISTRY_HOST>/the-grid/operator:v0.2.0
   helm pull oci://<REGISTRY_HOST>/charts/the-grid-synthetics --version 0.2.0
   ```

## CRD upgrade procedure

CRDs are stored in `charts/the-grid-synthetics/crds/` (Helm native). Helm installs CRDs
on first install but **does not upgrade them on `helm upgrade`** — this is intentional to
prevent destructive schema migrations.

When a release changes a CRD schema, include a note in the release notes and apply manually:

```bash
kubectl apply -f charts/the-grid-synthetics/crds/thegrid.io_synthetictests.yaml
kubectl apply -f charts/the-grid-synthetics/crds/thegrid.io_synthetictestruns.yaml
```

Run this **before** `helm upgrade` so the API server accepts the updated schema.

The CRD source files are generated by kubebuilder in `synthetics-operator/config/crd/bases/`.
When updating the operator API types, copy the two `thegrid.io_*.yaml` files into
`charts/the-grid-synthetics/crds/` as part of the release commit.
