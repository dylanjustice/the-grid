# Quickstart Validation Guide: The Synthetics Reporter

This guide describes how to validate the Synthetics Reporter end-to-end. It does not contain
implementation code — see `data-model.md` and `contracts/reporter-interface.ts` for the design,
and `tasks.md` (generated by `/speckit-tasks`) for the implementation steps.

## Prerequisites

- Node 23 installed (`nvm use 23`)
- A running Prometheus Pushgateway reachable at `http://localhost:9091`
  - Quickest local setup: `docker run -p 9091:9091 prom/pushgateway`
- The `packages/synthetics/` package built: `cd packages/synthetics && npm run build`
- The `playwright-synthetics/` suite has `@the-grid/synthetics` as a dependency (local workspace
  or published)

## Scenario 1 — Step metrics emitted for a passing test

**What this validates**: FR-001, FR-003, SC-001, SC-002

```bash
cd playwright-synthetics
PUSHGATEWAY_URL=http://localhost:9091 GRID_ENV=local npx playwright test tests/http-bin.spec.ts
```

**Expected outcome**: After the run completes, query the Pushgateway:

```bash
curl -s http://localhost:9091/metrics | grep synthetic_step_duration_seconds
```

You should see histogram output similar to:

```
# HELP synthetic_step_duration_seconds Duration of test steps in seconds
# TYPE synthetic_step_duration_seconds histogram
synthetic_step_duration_seconds_bucket{test_suite="HTTP Methods",test_name="HTTP Methods",step_name="GET",status="success",environment="local",le="0.1"} 0
synthetic_step_duration_seconds_bucket{...,le="0.25"} 1
...
synthetic_step_duration_seconds_sum{...} 0.182
synthetic_step_duration_seconds_count{...} 1
```

**Verify**: All five labels (`test_suite`, `test_name`, `step_name`, `status`, `environment`) are
present on every line. `status="success"` appears. No prom-client imports in `http-bin.spec.ts`.

## Scenario 2 — Test histogram emitted with correct test_suite

**What this validates**: FR-002, FR-004, SC-002

Same run as Scenario 1. Query:

```bash
curl -s http://localhost:9091/metrics | grep synthetic_test_duration_seconds
```

**Expected outcome**: One observation per test in the suite.

- `test_suite` matches the outermost describe block name in `http-bin.spec.ts`
- If the file has no describe block, `test_suite` equals `http-bin.spec.ts`
- `status="success"` for passing tests
- `step_name` label is absent (test-level metric only has four labels)

## Scenario 3 — Timeout reported as `status="timeout"`

**What this validates**: FR-003, SC-003

Temporarily modify one test to time out (set `test.setTimeout(1)` to force a 1ms timeout).
Run the suite, then query:

```bash
curl -s http://localhost:9091/metrics | grep 'status="timeout"'
```

**Expected outcome**: The timed-out test appears in `synthetic_test_duration_seconds` with
`status="timeout"`. Other tests are unaffected. The suite exits non-zero but the Pushgateway
push still completes.

---

## Scenario 4 — Pushgateway unavailable does not abort tests

**What this validates**: FR-007, SC-005

Run with an unreachable Pushgateway URL:

```bash
PUSHGATEWAY_URL=http://localhost:19999 npx playwright test tests/http-bin.spec.ts
```

**Expected outcome**:

- Tests pass (exit code 0, or non-zero only if tests fail for other reasons)
- A warning line appears on stderr: something like `[SyntheticsReporter] push failed: ...`
- No test is marked as failed due to the push error

## Scenario 5 — Operator metric removed (no conflict)

**What this validates**: FR-009, SC-004

After removing `syntheticTestMetrics()` from the operator:

```bash
cd synthetics-operator
make test
```

**Expected outcome**: All operator unit tests and e2e tests pass. Verify the Argo workflow
metrics endpoint no longer exposes `synthetic_test_duration_seconds`:

```bash
# Port-forward the Argo Workflows metrics
kubectl port-forward -n the-grid-workflows svc/argo-workflows-metrics 9090:9090 &
curl -s http://localhost:9090/metrics | grep synthetic_test_duration_seconds
# Expected: no output
```

## Scenario 6 — No prom-client boilerplate in test files

**What this validates**: SC-001 (zero-boilerplate)

After the reporter is wired up:

```bash
grep -r "prom-client\|new Registry\|new Histogram\|startTimer\|Pushgateway" playwright-synthetics/tests/
```

**Expected outcome**: No matches. All prom-client usage is inside `packages/synthetics/src/`.
