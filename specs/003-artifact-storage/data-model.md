# Data Model: Artifact Storage

**Date**: 2026-10-20

## Entities

### ArtifactStorageSpec (expanded)

New fields added to the existing `ArtifactStorageSpec` struct in `synthetics-operator/api/v1alpha1/synthetictest_types.go`.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `enabled` | bool | yes | Feature gate. When false all other fields are ignored. |
| `bucket` | string | when enabled | The object storage bucket name. |
| `endpoint` | string | no | S3-compatible API endpoint URL. Leave empty for AWS S3 default endpoint. Set for MinIO (`http://minio:9000`) or GCS interop (`https://storage.googleapis.com`). |
| `region` | string | no | AWS/GCS region (e.g. `us-east-2`). Optional for MinIO. |
| `credentialsSecret` | string | no | Name of a Kubernetes Secret in the same namespace containing keys `accessKey` and `secretKey`. Used for static credential mode. |
| `serviceAccountAnnotations` | map[string]string | no | Annotations merged onto the workflow ServiceAccount. Used for IAM delegation mode. Example: `{"eks.amazonaws.com/role-arn": "arn:aws:iam::123456789:role/the-grid-uploader"}`. |

**Validation rules**:
- `bucket` must be non-empty when `enabled: true`
- `credentialsSecret` and `serviceAccountAnnotations` are mutually exclusive; if both are set, IAM delegation wins and a warning is logged
- `endpoint` must be a valid URL if non-empty

**State transitions**: none — this is pure configuration; no lifecycle state machine

### artifact-repositories ConfigMap

The operator generates one ConfigMap per `SyntheticTest` in the same namespace. The controller uses `ctrl.SetControllerReference` so the ConfigMap is garbage-collected with the `SyntheticTest`.

| Field | Source |
|-------|--------|
| `metadata.name` | `<synthetictest-name>-artifact-repository` |
| `metadata.namespace` | same as `SyntheticTest` |
| `data.default` | YAML-encoded Argo `ArtifactRepository` derived from `ArtifactStorageSpec` |

The `data.default` key contains the Argo artifact repository configuration. See `contracts/artifact-repository-configmap.yaml` for the full schema.

---

### Artifact Credentials Secret (static mode only)

Operator creates this Secret when `credentialsSecret` is set. Alternatively the operator reads an existing Secret by that name — it does NOT create the Secret; the operator expects it to exist (the operator can't know the credentials). This follows the same pattern as image pull secrets.

| Field | Value |
|-------|-------|
| `metadata.name` | value of `spec.artifactStorage.credentialsSecret` |
| `metadata.namespace` | same as `SyntheticTest` |
| `data.accessKey` | base64-encoded S3 access key ID |
| `data.secretKey` | base64-encoded S3 secret access key |

The Secret is NOT owned by the `SyntheticTest` (it may pre-exist or be shared). The operator references it by name; it does not create or delete it.

### SyntheticTestRun.Status.ArtifactURL (existing field)

Already declared in `synthetics-operator/api/v1alpha1/synthetictestrun_types.go`. The `SyntheticTestRunController.artifactURL()` already extracts this from the completed workflow's node outputs.

| Field | Type | Format |
|-------|------|--------|
| `status.artifactURL` | string | `s3://<bucket>/<test-name>/<workflow-name>/playwright-report` |

Example value: `s3://the-grid-artifacts/httbin-synthetic/httbin-synthetic-abc12345/playwright-report`

**Population**: Set by `SyntheticTestRunController.Reconcile` once the parent `Workflow` reaches a completed phase. Empty until then.

---

### Workflow Artifact Path (derived)

The path within the bucket for each artifact package is determined by the `keyFormat` in the `artifact-repositories` ConfigMap. The fixed format is:

```
{{workflow.labels["the-grid.io/synthetic-test"]}}/{{workflow.name}}/playwright-report
```

- `{{workflow.labels["the-grid.io/synthetic-test"]}}` resolves to the `SyntheticTest` name (e.g., `httbin-synthetic`)
- `{{workflow.name}}` resolves to the Argo `Workflow` name (e.g., `httbin-synthetic-abc12345`)
- `playwright-report` is the literal artifact name

This label is already applied to every workflow generated by `WorkflowBuilder.BuildCronWorkflow`.

## Relationships

```
SyntheticTest
  └── spec.artifactStorage           (new expanded fields)
  └── [owns] <name>-config          (existing ConfigMap for test source)
  └── [owns] <name>-artifact-repository  (new ConfigMap, operator-created)
  └── [owns] <sa-name> ServiceAccount   (existing, annotations added when IAM mode)
  └── [owns] CronWorkflow
       └── spec.artifactRepositoryRef → <name>-artifact-repository ConfigMap
       └── templates[run].outputs.artifacts[playwright-report]
              └── path: /app/playwright-report

Workflow (each CronWorkflow execution)
  └── status.nodes[*].outputs.artifacts[playwright-report].s3.key
  └── [triggers] SyntheticTestRunController

SyntheticTestRun
  └── status.artifactURL ← extracted from Workflow artifact key
```
